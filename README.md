# Журнал ключей

Сайт, где по адресу можно быстро узнать, где висит ключ: **шкаф, номер кольца, номер ящика** и заметка.
Вход только по логину и паролю. Добавлять и менять шкафы, ключи и пользователей может только администратор.

## Установка на сервер Windows (автозапуск)

Нужны **git** (`winget install Git.Git`) и права администратора. Python программа поставит сама.

1. **Скачать сайт на сервер:**
   ```
   git clone -b claude/admiring-hopper-oqhl9j https://github.com/fantome6463/keys.git
   ```
2. **Запустить `keys.bat`.** При первом запуске соберётся `Keys.exe` и откроется окно управления.
3. Нажать **«Установить и запустить»** — поставится Python и библиотеки, сайт добавится в автозапуск
   (задача «Журнал ключей» в Планировщике Windows), откроется порт в брандмауэре.
4. Нажать **«Логины и пароли»** и задать два входа: **админ** (может всё добавлять и менять) и **общий для сотрудников**
   (видят всё, меняют только примечания, ИБП и Электрон).

Сайт открывается с любого компьютера или телефона в сети работы: `http://<IP сервера>:8090`.

Автозапуск включается и выключается галочкой «...» → **«Запускать вместе с компьютером»**. Без неё сайт
запускается кнопкой **«Запустить сайт»** и работает, пока компьютер включён (удобно, пока сайт стоит на ноутбуке).

С автозапуском:
- сайт запускается при включении сервера, даже если никто не вошёл в Windows;
- если сайт упал — через несколько минут поднимется снова;
- раз в сутки делается копия базы в папку `backups\` (хранятся 30 последних).

В окне видно, работает ли сайт, есть ли админ, когда была последняя копия и есть ли обновления. Кнопки:
*Установить и запустить*, *Обновить сайт* (скачивает новую версию из GitHub и перезапускает),
*Открыть сайт*, *Логины и пароли* (там же меняется забытый пароль). В меню «...» — перезапуск,
резервная копия, журнал сервера, домен, *Убрать из автозапуска*. Закрытие окна на работу сайта не влияет.

То же из консоли: `keys.bat status | install | start | stop | autostart on|off | admin | staff | update | restart | backup | uninstall`.

### Домен с HTTPS (необязательно)

Если на этом сервере есть CRM «Лаборатория 3Д» с Caddy (как у маршрутника), сайт можно открыть и по домену:
в DNS добавьте запись `A` на IP сервера, затем в окне «...» → «Указать домен». Программа положит
`keys.caddy` в `New_Lab_3D\deploy\sites.d\`, и Caddy сам получит сертификат.

## Как пользоваться

- **Поиск** — пишете часть адреса (`ленина 12`), регистр не важен. Ищет также по колонке «Информация».
- **Шкафы** внизу главной страницы — нажмите, чтобы увидеть все ключи в шкафе.
- **Админ**: `+ Шкаф`, `+ Ключ` (есть кнопка «Сохранить и добавить ещё» для быстрого переноса журнала), «Изменить»/«Удалить» у каждой записи.

## Безопасность

- Все данные в одном файле `keys.db`, копии — в `backups\`. Время от времени копируйте их ещё и на флешку или другой компьютер. Базу и `.secret_key` нельзя публиковать (они в `.gitignore`).
- Пароли хранятся в виде хэшей, есть защита от подбора (5 попыток за 10 минут) и от CSRF.
- Лучше держать сайт только во внутренней сети. Если выставлять в интернет — только через HTTPS
  (например, nginx/Caddy перед приложением) и с переменной окружения `KEYS_HTTPS=1`.
- Забыли пароль — «Логины и пароли» в окне управления (или `keys.bat admin` / `keys.bat staff`).
